# Hyeonseung Shin — academic homepage

Personal research website: https://hyeonseungshin90.github.io/

This is a dependency-free static site for GitHub Pages. Edit data.js to update the profile, affiliations, and publication list. Keep publication types accurate: Journal, Conference, or Preprint.

Files:
- index.html: page structure and metadata
- style.css: responsive and print styles
- app.js: publication filtering and rendering
- data.js: editable profile and publication metadata
- assets/qr.png and assets/qr.svg: QR codes for the homepage
- .nojekyll: serve as plain static files

Publishing:
GitHub repository Settings > Pages > Deploy from a branch > main > /(root).
