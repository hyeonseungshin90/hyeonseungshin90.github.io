# Hyeonseung Shin — academic homepage

Personal research website: https://hyeonseungshin90.github.io/

This is a dependency-free static site for GitHub Pages. Edit data.js to update the profile, research areas, affiliations, education, projects, teaching, awards, and publication list. Publication types are Journal, Conference, and Preprint.

Files:
- index.html: page structure and metadata
- style.css: responsive and print styles
- app.js: content rendering and publication filtering
- data.js: profile and professional records
- assets/qr.png and assets/qr.svg: QR codes for the homepage
- .nojekyll: serve as plain static files

Publishing:
GitHub repository Settings > Pages > Deploy from a branch > main > /(root).
Update the version suffix on script/style URLs in index.html when assets change.
